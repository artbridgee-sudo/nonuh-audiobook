# 논어통독 오디오북

진다청 지음, 김태만 옮김 『논어통독』 전권(98개 장, 20시간 33분)을 텍스트를 보며 들을 수 있는 설치형 웹앱입니다.

책 본문과 음성은 모두 암호화되어 있어, 열쇠가 담긴 링크를 받은 분만 열 수 있습니다. 이 저장소의 파일을 내려받아도 링크의 열쇠 없이는 읽거나 들을 수 없습니다.

## 받는 분께 보낼 설치 안내

1. 받은 링크를 누르면 바로 열립니다. 비밀번호를 따로 넣을 필요가 없습니다. 카카오톡 안에서 열렸다면 화면의 **브라우저로 열기**를 누르거나, 메뉴에서 **다른 브라우저로 열기**를 고릅니다.
2. 아이폰: Safari 아래쪽 **공유** 버튼 → **홈 화면에 추가** → **추가**
   안드로이드: Chrome 오른쪽 위 **⋮** → **앱 설치** (또는 **홈 화면에 추가**)
3. 홈 화면의 "논어통독" 아이콘으로 엽니다.
4. 인터넷 없이 들으려면 와이파이에서 목차를 열고 **전체 저장**(약 212MB)을 누릅니다. 아이폰은 반드시 설치한 앱 안에서 저장해야 합니다.

## 사용법

- 문장을 누르면 그 문장부터 재생됩니다.
- 왼쪽 아래 1.0× 버튼: 재생 속도(0.8~2배), 오른쪽 아래 타이머: 15·30·60분 또는 이 장 끝에서 멈춤
- 들은 위치는 기기에 저장되어 다음에 열면 이어서 재생됩니다.
- 각 장 앞의 한문 원문은 화면에만 표시하고 음성으로는 읽지 않습니다.

음성은 Microsoft 신경망 음성(선희)으로 합성했습니다. 일부 인명이나 한자어를 틀리게 읽을 수 있습니다.
